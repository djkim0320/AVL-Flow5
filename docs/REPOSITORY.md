# GitHub 소스 배포 범위

이 저장소는 DBF Studio와 Python 계산부의 소스 배포본이다. 실물 비행 안전성이나 전체 임무 수렴을 인증한 결과물이 아니다.

포함한 파일은 `src/`, `ui/`의 실행 코드, `tests/`, `ui/tests/`, 중립 입력 템플릿, YAML 예제, 모델링 생성 스크립트·AVL 입력, 노트북, 설명서다. 복합 공력표 구현 기록과 UI 검증 화면도 포함한다.

다음 항목은 로컬에 남겨 두며 Git으로 전송하지 않는다.

- `.venv`, `node_modules`, 캐시와 로그
- `vendor/`의 설치된 해석기 실행파일·DLL·다운로드 묶음
- `ui/data/`의 사용자 프로젝트·등록 모델·해석 결과
- `outputs/`, 모델별 `runs/`, 공력 실행 원본·진단 기록
- 생성된 STEP·STL·GLB 등 CAD와 대용량 재생·시계열 자료
- `ui/design/`의 수정 전 백업과 임시 검증 폴더

공식 해석기는 `scripts/fetch_avl.py`, `scripts/fetch_flow5.py`로 설치한다. 출처와 해시 검사를 포함한다. [외부 구성요소 안내](THIRD_PARTY.md)의 라이선스·출처 설명은 설치한 외부 구성요소에 관한 설명이며, 이 Git 저장소에 실행파일을 동봉했다는 뜻은 아니다.

등록 모델이 없는 상태에서 시작하는 것이 정상이다. STEP을 불러온 뒤 기체 정의에서 부품·질량·CG·관성·공력 면을 입력하고 새 모델로 등록한다. 다른 PC의 등록 모델이나 계산 결과를 몰래 대신 사용하지 않는다.

## 검사 범위

범용 UI 테스트와 `tests/test_hybrid_compose.py`, `tests/test_ui_generated_pipeline.py`는 자체 생성 기체를 사용한다. 해석기 실행 테스트는 실제 프로그램 설치가 필요하며, 가짜 공력값으로 대신하지 않는다.

개발 PC의 전체 Python 206개 검사 통과 기록에는 보관된 임무·접촉 자료를 읽는 검사가 포함돼 있다. 과거 기록을 제외한 소스 배포본에서 전체 `pytest`가 그대로 통과한다고 주장하지 않는다. H1·N3 모델별 생성·회귀 스크립트와 노트북 일부도 원래 자료를 먼저 생성하거나 보관 자료를 복원해야 한다. 로컬 절대 경로가 기록된 과거 문서는 실행 입력으로 자동 적용하지 않는다.

새 소스 배포본의 실제 확인 결과는 최초 업로드 커밋과 함께 기록한다. 설치·일반 검사 명령은 [README](../README.md#github에서-받아-실행하기)를 따른다.
