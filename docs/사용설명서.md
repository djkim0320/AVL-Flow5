# DBF Studio 사용설명서

2026-09-28 구현 기준

이 도구는 사용자가 불러온 기체에 윈치와 센서 역할의 질점을 배치하고, 전개 비행 중 안정성과 줄 회수 응답을 계산한다. 기체별로 부품 역할·질량·무게중심(CG)·관성·공력 면을 등록해 사용한다. S27은 기능 확인에 사용한 테스트 모델이며 기체 이름에 따른 전용 계산은 없다.

작업 순서는 **기체 불러오기 → 윈치·질점 배치 → 부품 지정 → 질량·CG·관성 입력 → 공력 면 정의 → 모델 등록 → 해석 실행 → 결과 확인**이다. 입력을 마치지 못했어도 프로젝트를 저장하고 이어서 작업할 수 있다.

**1. 실행과 S27 초안 열기**

[Start_DBF_UI.bat](../Start_DBF_UI.bat)를 더블클릭한다. 브라우저가 열리지 않으면 서버 실행 후 [DBF Studio](http://127.0.0.1:8767/)에 접속한다. 처음 설치한다면 [설치 명령](../README.md#github에서-받아-실행하기)을 먼저 따른다.

사용하던 브라우저에는 최근 배치가 자동 복원된다. 다른 브라우저에서는 자동 저장 내용이 다를 수 있다. S27 시험 초안을 직접 열려면 상단 **프로젝트 열기**를 누르고 아래 파일을 선택한다.

[S27 UI 시험 초안](<D:/DBF/안정성 툴/outputs/generic_aircraft_ui_20260928/S27_ui_test_draft.dbf.json>)

S27 초안과 아래 S27 화면은 개발 PC의 로컬 기록이며 GitHub 소스 배포에 포함하지 않는다. 해당 파일이 없다면 다음 절에서 본인의 기체 CAD를 불러온다.

초안에는 S27 형상, 윈치, 0.6 kg 질점, 2.4 m 줄과 일부 기체 정의가 들어 있다. **기체 질량 5 kg과 CG (800, 0, -418.5) mm는 입력·드래그 시험값이다. 실제 S27 값으로 사용하지 않는다.** 관성·추진·전체 공력 면은 아직 입력하지 않았고 부품 역할도 일부만 지정했다. 이 파일을 열었다고 바로 S27 해석이 준비되는 것은 아니다.

**2. 새 기체 불러오기**

왼쪽 **모델 불러오기**에서 **파일 단위·축 설정**을 펼친다. 원본 CAD의 축 방향을 먼저 고른 뒤 **기체 불러오기**를 누르거나 STEP·STL·GLB 파일을 3D 화면으로 끌어놓는다.

| 항목 | 설정 방법 |
|---|---|
| 파일 단위 | STEP은 변환 과정에서 mm로 통일한다. STL·GLB는 원본 파일에 맞춰 mm·cm·m를 선택한다. |
| 파일 축 | 원본 CAD의 전방·우측·상방 방향과 일치하는 항목을 선택한다. 불러온 뒤의 내부 좌표는 X 전방, Y 우측, Z 하방(FRD)이다. |
| 형상 상태 | 현재 해석은 문이 열린 형상을 사용한다. 문 개폐 동작은 이 화면에서 설정하지 않는다. |

불러온 뒤 측면·상면·후면 보기로 앞뒤와 위아래를 확인한다. 기체를 선택하면 오른쪽 선택 속성에 외곽 크기가 표시된다. 원본 치수와 비교해 배율도 확인한다.

단위·축 설정은 파일을 불러올 때 적용된다. 잘못 가져왔다면 설정을 바꾸고 다시 불러온다. **새 기체를 불러오면 기존 윈치·질점 배치와 기체 정의가 초기화되므로, 교체 전에 파일 저장을 한다.**

**3. 화면 조작**

| 동작 | 조작 |
|---|---|
| 시점 회전 | 3D 화면의 빈 곳을 왼쪽 버튼으로 드래그 |
| 시점 이동 | 휠 버튼을 누른 채 드래그 또는 우클릭 드래그 |
| 확대·축소 | 휠 돌리기 |
| 모델 위치 이동 | 모델 또는 이동 축 드래그. 정확한 값은 오른쪽 좌표 칸에 입력 |
| 이동·회전 도구 | G / R |
| 선택한 모델 확대 | F |
| 정해진 방향에서 보기 | 상단의 측면·상면·후면 |
| 되돌리기·다시 실행 | Ctrl+Z / Ctrl+Shift+Z |

기체는 기본적으로 위치가 고정된다. 기체 자체를 옮겨야 할 때만 오른쪽 **기체 위치 고정**을 해제한다. CG 편집은 기체 위치를 고정한 상태에서도 가능하다. CG는 위치만 지정하므로 회전 도구를 사용하지 않는다.

**4. 윈치와 질점 배치**

1. **윈치 추가**를 누른다.
2. 윈치를 드래그하거나 오른쪽 위치 좌표를 입력한다. 파란 점이 줄이 나오는 위치다.
3. **센서 역할 질량**에 kg 단위로 입력한다.
4. **전개할 줄 길이**에 m 단위로 입력한다.
5. **질점 추가 · 줄 자동 연결**을 누른다.
6. **줄 세부 설정**에서 줄 직경을 mm 단위로 확인한다.

질점은 윈치 아래 min(20 mm, 전개 길이의 5%) 위치에 수납한 모습으로 표시된다. 입력한 줄 길이는 전개 목표다. 질점을 따로 드래그하거나 센서 모델 파일을 불러오는 단계는 없다. 윈치 위치를 바꾸면 질점도 따라 이동한다.

줄 길이는 날개폭에 자동 연동되지 않는다. 팀에서 날개폭의 1.5배로 시험하기로 했다면 `줄 길이 = 입력한 날개폭 × 1.5`를 계산해 넣는다. 이는 입력 방법의 설명이며 대회 규정 판정 기능은 아니다.

화면의 짧은 직선은 줄이 감긴 시작 상태를 나타낸다. 기본 연속 해석은 이 수납 위치에서 시작한다. 전개 비행·회수 단독 해석을 선택하면 완전 전개 평형을 별도로 계산한다. 직선이 기체와 겹친다는 안내는 실제 접촉 계산 결과가 아니다.

현재 견인 트림은 좌우 대칭 조건을 사용한다. 윈치 출구는 기체 CG에 대해 측방 오프셋이 없어야 한다. 즉, **기체의 로컬 좌표에서 윈치 출구 Y와 CG의 Y를 맞춘다.** 작업 화면에서 기체를 회전했다면 작업 원점 기준 Y와 기체 로컬 Y를 혼동하지 않는다.

**5. 부품 역할 지정**

왼쪽 **기체 정의 · 부품 / CG / 공력 면**을 누르고 **부품** 탭을 연다.

1. 3D에서 부품을 클릭하거나 오른쪽 **부품 목록**에서 선택한다.
2. 3D에서 Shift를 누른 채 클릭하면 여러 부품을 선택한다.
3. **선택 부품 역할**에서 역할을 고른다.
4. **역할 적용**을 누른다. 부품 하나를 선택했을 때는 이름도 바꿀 수 있다.

| 역할 | 지정 대상과 후속 작업 |
|---|---|
| 주익 | 주날개 외피. 이후 공력 면에 연결한다. |
| 수평 꼬리날개 | 수평 꼬리날개 외피. 이후 공력 면에 연결한다. |
| 수직 꼬리날개 | 수직 꼬리날개 외피. 이후 공력 면에 연결한다. |
| 조종면 | 따로 분리된 조종면 부품. 공력 면에 연결하고 실제 조종면 종류도 지정한다. |
| 동체 | 동체 부품. 양력면 모델에 동체 압력 분포가 자동 추가되지는 않는다. |
| 문 | 문 부품. 현재 전개 비행·회수에서는 불러온 상태를 유지한다. |
| 장비·구조물 | 배터리, 모터, 내부 구조물 등 |
| 공력 제외 | 양력면 생성에 사용하지 않는 표시용 형상 등 |

모델을 등록하려면 **미지정** 부품이 없어야 한다. 공력 제외를 선택해도 질량은 자동으로 제외되지 않는다. 실제 부품 질량은 전체 기체 값이나 부품별 합산에 포함한다.

**6. 질량·CG·관성 입력**

**질량·CG** 탭에서 입력 방식을 선택한다.

**기체 전체 값 입력**은 전체 기체의 질량·CG·관성 자료가 있을 때 사용한다. 기체 질량에 배터리·모터·윈치를 포함하고, 별도로 계산하는 줄과 센서 질점은 제외한다.

CG 좌표를 입력한 뒤 **CG를 3D에서 이동**을 누르면 분홍색 CG 표시와 이동 축이 나타난다. 축을 드래그하면 좌표가 바뀌며 숫자로도 수정할 수 있다. **형상 중앙에 CG 초안 배치**는 편집 시작점을 잡는 기능이다. 형상 중앙을 실제 CG로 추정하지 않는다.

![S27에서 CG를 편집하는 화면. 표시된 질량과 CG는 조작 시험값이다.](<D:/DBF/안정성 툴/outputs/generic_aircraft_ui_20260928/S27_cg_editor.png>)

**부품별 값 합산**은 부품마다 질량·CG·관성을 입력하고 **전체 질량·CG·관성 계산**을 누른다. 프로그램이 질량 가중 CG와 평행축 정리로 전체 관성을 합산한다. 중복 CAD나 표시용 부품은 **질량 합산에서 제외**로 처리한다. 이 목록은 불러온 CAD 부품 기준이므로, CAD에 없는 장비까지 포함한 전체 물성을 알고 있다면 전체 값 입력 방식을 사용한다.

| 입력 | 단위와 기준 |
|---|---|
| 질량 | kg |
| 기체·부품 CG | mm, 불러온 기체의 CAD 원점 기준 |
| Ixx·Iyy·Izz | kg·m², 해당 기체 또는 부품의 CG 기준 |
| Ixy·Ixz·Iyz | 같은 CG와 기체축을 기준으로 한 관성 행렬 성분 |

부품별 관성도 기체축으로 표현한 값을 넣는다. CAD에서 부품 고유 좌표계로 내보냈다면 먼저 기체축으로 변환해야 한다. CAD가 출력하는 관성곱과 관성 행렬의 교차항은 부호 규약을 확인한다. 초기 교차항 0은 입력 편의를 위한 값이므로 실제로 0을 써도 되는지 확인한다.

관성이 없으면 STEP의 모양만으로 자동 산출하지 않는다. CAD의 재료·질량 정보나 별도로 계산한 관성값이 필요하다. 입력한 관성이 물리적으로 성립하지 않으면 등록을 거부한다.

**7. 공력 면과 조종면 정의**

부품 역할 지정만으로 공력 계산이 준비되지는 않는다. 날개 단면과 조종면을 **공력 면** 탭에서 정의한다.

1. **공력 면** 탭을 연 상태에서 3D의 해당 부품을 클릭한다. 여러 부품이면 Shift를 누른 채 선택한다.
2. **선택 부품으로 면 추가**를 누른다. 다음 면을 추가할 때도 이 탭을 유지한 채 3D에서 새 부품을 선택한다.
3. 면 이름과 **단면 절단 축**을 정한다. 수평 날개는 Y, 수직 날개는 Z를 선택한다.
4. 오른쪽 반쪽 날개만 정의해 복제할 때 **오른쪽 반쪽을 좌우 대칭 복제**를 켠다. 양쪽 전체를 이미 정의했다면 다시 복제하지 않는다.
5. **절단 위치 제안**을 누르거나 **단면 위치**에 m 단위 좌표를 쉼표로 구분해 적는다.
6. **CAD에서 단면 추출**을 누른다.
7. 각 단면을 펼쳐 앞전 위치·시위·설치각·에어포일을 확인한다.

단면 추출은 선택한 CAD 메시를 실제로 자른다. 내부 구조물이나 떨어진 여러 외피가 한꺼번에 선택됐거나 날개 끝면을 정확히 잘랐을 때는 실패할 수 있다. 이때 부품 선택과 절단 위치를 수정한다. 추출에 실패한 단면을 임의의 에어포일로 바꾸지는 않는다.

**절단 위치 제안**은 형상 경계에서 약간 안쪽을 고른다. 제안값으로 추출한 것만 사용하면 루트·팁 면적이 빠질 수 있으므로 실제 날개 끝과 단면 범위를 확인한다. Y 방향 면은 Y 증가 순서, Z 방향 면은 Z 감소 순서로 단면을 입력한다.

수동으로 정의하려면 **단면 직접 추가**를 사용한다. 에어포일은 NACA 4자리 번호 또는 DAT 파일로 입력한다. DAT는 시위 1로 정규화한 x/c, y/c 좌표를 뒷전→앞전→뒷전 순서로 작성한다. 선택한 형상과 맞는 단면인지 사용자가 확인한다.

| 단면 입력 | 화면 단위 |
|---|---|
| 절단할 단면 위치 | m |
| 앞전 X·Y·Z | mm, CAD 원점 기준 |
| 시위 | m |
| 설치각 | 도(°) |
| 힌지 x/c | 앞전 0, 뒷전 1인 무차원 위치 |

**조종면**에서 없음·승강타·에일러론·방향타를 고른다. 조종면은 해당 공력 면의 전체 span에 적용된다. 날개 끝부분에만 에일러론이 있다면 고정 구간과 조종 구간을 별도 면으로 나눈다. 같은 CAD 부품을 여러 면에 연결해도 되지만 span 구간이 겹치면 등록을 거부한다. 현재 견인 트림에는 승강타로 지정한 피치 조종면이 필요하다.

주익·꼬리날개·조종면으로 지정한 부품은 모두 공력 면에 연결해야 한다. 화면에 표시되는 공력 면 윤곽과 실제 날개를 비교한다.

**8. 기준 치수·추진 입력과 모델 등록**

공력 면 탭 아래 **기준 치수·추진**을 입력한다.

| 항목 | 입력할 내용 |
|---|---|
| 날개 면적 | 공력계수에 사용할 기준 면적, m² |
| 평균 시위 | 기준 시위, m |
| 날개폭 | 기준 폭, m |
| 추가 항력계수 | 양력면 공력 외에 모델에 더할 항력계수와 그 가정 |
| 최대 추력 | 해당 시험에서 사용할 추력 상한, N |
| 추력 작용점 | CAD 원점 기준 X·Y·Z, mm |

값을 모른다고 항력이나 추력을 0으로 대체하지 않는다. 설계값·측정값·가정값 중 어느 것을 썼는지 아래 출처 칸에 남긴다.

**확인·등록**에서 기체 이름, 자료 구분, 형상·물성 출처와 가정을 적는다. **해석 입력 확인**을 누르고 누락이나 오류를 수정한다. 단면·조종면·물성·좌표를 확인한 뒤 확인란을 체크하고 **해석 모델 등록**을 누른다. 등록된 모델이 해석 화면에 선택된다.

등록은 공력 입력을 준비하는 단계다. 실제 공력표는 해석을 실행할 때 계산한다. 새 기체의 질량·관성·CG·부품 역할·공력 면을 바꾸면 다시 등록해야 한다. 이전 등록 모델에 수정 내용이 자동으로 덮어써지지는 않는다.

flow5를 선택하려면 기체 정의에서 **flow5의 종·횡 분리 근사 사용에 동의**를 확인하고 등록한다. 현재 자동 연결은 대칭 수평면과 기울어지지 않은 수직면으로 제한되며, 출력되지 않는 종·횡 교차 회전율 미계수에는 명시한 근사를 사용한다. 새 범용 정의의 실제 연결 검증은 AVL로 완료했고 flow5는 입력 변환 경로를 검사한 상태다.

**9. 해석 조건 설정**

상단 **해석** 또는 왼쪽 **해석 조건 설정**을 누른다. **등록 모델**이 현재 기체와 일치하는지 먼저 확인한다. 등록 모델을 바꾸면 해석 조건도 그 모델의 등록값으로 바뀐다.

| 해석 조건 | 시작 상태와 계산 내용 |
|---|---|
| 비행 시작 → 전개 → 전개 후 비행 → 회수 · 기본 | 줄이 감긴 비행 상태에서 시작해 네 구간을 연속 계산한다. 구간이 바뀌어도 위치·속도를 초기화하지 않는다. |
| 전개 비행 | 줄이 완전히 전개된 비행 평형에서 시작한다. 트림, 고정 길이에서의 선형 안정성, 지정 시간의 움직임을 계산한다. |
| 회수 | 완전 전개 평형에서 바로 줄을 감는다. 입력한 평균 속도와 회수 후 남길 길이로 회수 시간을 정한다. |

전체 과정을 보려면 기본 연속 해석을 선택한다. **비행 시작은 입력한 고도·속도로 이미 비행 중인 상태**이며 이륙은 포함하지 않는다. 문은 불러온 각도를 유지하고 포획·문 닫힘은 계산하지 않는다. 기존 **전개 비행**과 **회수**는 별도의 단독 해석으로 남아 있으며, 두 단독 실행을 서로 이어 붙이지는 않는다.

공력 해석기를 선택하고 **공력표 선택과 새 계산 범위**를 펼친다. 첫 실행은 새 계산을 사용한다. 같은 등록 모델에서 만든 공력표가 있으면 이를 선택해 재사용할 수 있다. flow5 표는 속도도 같아야 한다.

받음각·옆미끄럼각·승강타각은 **최소·최대·계산점 수 슬라이더**로 정한다. 계산점 수를 모두 늘리면 조합 수가 곱으로 증가한다. 저장된 표를 선택한 상태에서 범위를 수정하려면 새 계산을 선택하거나 **저장된 공력표 대신 실제 해석기로 다시 계산**을 켠다.

비행 조건에는 속도·고도·공기 밀도를 입력한다. **고도를 바꿔도 밀도는 자동으로 바뀌지 않으므로 별도로 입력한다.** 기체 정의에서 등록한 질량·관성은 이 화면에서 직접 수정하지 않는다. 변경하려면 **기체 정의에서 부품·CG·공력 면 편집**으로 돌아가 수정 후 재등록한다.

줄 물성에는 선밀도·축강성 EA·감쇠·분할 수와 수직·접선 항력계수를 입력한다. 질점 질량·윈치 위치·줄 길이·직경은 배치 화면에서 가져온다. 처음 채워진 줄 물성도 실제 줄의 측정값인지 확인한다.

연속 해석에서는 **전개 전 비행 시간**(기본 2초), **전개 평균 속도**, **전개 후 비행 시간**(기본 60초), **회수 평균 속도**, **회수 후 남길 줄**을 설정한다. 화면에 전개 시작·완료, 회수 시작·종료 시각이 표시된다. 시작 줄 길이는 min(20 mm, 전개 길이의 5%)이다. 회수 후 남길 줄은 이 시작 길이 이상, 전개 목표 길이 미만이어야 한다. 전개·회수는 처음과 끝에서 가감속하며 최대 속도는 평균의 약 1.5배다. 총 계산 시간은 600초 이하로 설정한다.

전개 비행 단독 해석에서는 **비행 계산 시간**과 **기체 피치 교란**을 정한다. 회수 단독 해석에서는 **회수 평균 속도**와 **회수 후 남길 줄**을 입력한다. 연속 해석의 CSV와 3D 재생에는 현재 구간과 줄 길이가 함께 표시된다.

**적분 설정**의 최대 적분 간격은 계산 중 한 번에 진행할 시간의 상한이다. 적분 제한 시간은 실제 대기 시간을 제한한다.

**고도·속도 제어 → 승강타·추력으로 고도와 속도 유지**를 켜면 위에서 입력한 고도·속도를 목표로 전개 전 비행부터 회수까지 제어한다. 고도 오차·상승률로 목표 피치를 정하고, 피치 오차·피치율로 승강타를 움직인다. 속도 오차는 추력으로 보정한다. 승강타 방향은 실제 공력표의 CG 기준 피칭 모멘트 변화로 확인하고, 승강타·추력은 입력한 한계 내에서 작동한다. 선형 고유값에는 제어를 적용하지 않는다.

제어 설정이 없던 프로젝트에는 시험용 기본 이득을 표시한다. 기체별 조정이 필요하며 **돌풍·조종 입력·제어기 세부 설정**에서 이득·제한값을 수정한다. 완전한 상태 측정과 즉시 작동하는 구동기를 가정한다. 롤·방향 제어와 적분 보상은 없으므로 작은 정상 오차가 남을 수 있다. 결과에서 목표·실제 고도와 속도, 승강타·추력, 최대 오차와 제한값에 머문 시간 비율을 확인한다.

계산 자원은 최대 12개 CPU까지 선택할 수 있다. AVL은 가용 메모리에 따라 동시에 실행할 수를 줄이며 모든 계산 단계가 병렬로 실행되지는 않는다.

**10. 실행과 결과 확인**

오른쪽 **입력 확인**을 누른다. 기체 연결이나 물성 오류가 나오면 해당 입력을 수정한 뒤 다시 확인한다. 준비가 끝나면 **해석 실행**을 누른다.

진행 상황에는 공력 준비 → 트림 → 안정성 → 시간 적분 → 결과 작성 단계가 표시된다. 해석 종류에 따라 일부 단계는 생략된다. 실행 버튼을 누른 순간의 배치와 조건이 사용되므로 계산 중 화면을 편집해도 진행 중인 해석은 바뀌지 않는다.

결과는 **진행 상황과 결과** 또는 **최근 해석**에서 연다. 해당 실행에 생성된 보고서·재생·결과 파일 링크를 사용한다.

| 결과 | 확인할 내용 |
|---|---|
| 트림 받음각·승강타·추력 | 해당 하중을 지탱하는 평형 조건. 설정한 공력 범위와 추력 상한 안에 있는지 확인한다. |
| 안정성 결과 | 감쇠·증가·거의 중립인 모드를 구분한다. 완료 또는 양의 성장률 미검출만으로 안전 판정을 내리지 않는다. |
| 최대 장력·자세 변화 | 같은 조건에서 줄 길이·질량·윈치 위치·회수 속도를 바꿨을 때 어떻게 달라지는지 비교한다. |
| 회수 목표 길이 도달 | 지정한 줄 길이까지 계산됐는지 확인한다. 실제 포획 성공을 뜻하지 않는다. |
| 계산 상태 | 계산 완료, 일부 구간 계산, 실패를 구분하고 마지막 계산 시각과 중단 원인을 확인한다. |

질점에는 센서 형상·공력·회전이 없다. 현재 해석은 기체·문과의 접촉, 가이드 간섭, 포획 충격도 계산하지 않는다. 따라서 재생 화면과 장력 결과만으로 실물 장치의 간섭이나 포획 안전성을 판단할 수 없다.

**11. 저장과 수정 후 재해석**

상단 **파일 저장**은 기체 형상·배치·기체 정의·해석 조건을 담은 프로젝트 파일을 내려받는다. **프로젝트 열기**로 다시 작업할 수 있다. **배치 내보내기**는 다른 계산 코드에 전달할 좌표·연결 정보용이며, 작업을 그대로 이어갈 목적이면 파일 저장을 사용한다.

| 바꾼 내용 | 다음 작업 |
|---|---|
| 부품 역할, 기체 질량·CG·관성, 단면·조종면 | 기체 정의에서 확인 후 새 버전 등록 |
| 새 기체 파일 | 새 기체 정의와 윈치·질점 배치부터 진행 |
| 질점 질량, 줄 길이·직경, 윈치 위치 | 배치 수정 후 입력 확인과 재해석. 실제 윈치 이동으로 기체 물성도 변했다면 기체 정의를 함께 수정 |
| 속도, 고도, 밀도, 회수 속도 | 해석 조건 수정 후 입력 확인. 공력표의 적용 조건도 확인 |
| 공력 계산 범위 또는 해석기 | 해당 조건으로 실제 공력표 새 계산 |

다른 PC에서는 프로젝트 파일 외에도 실행 환경과 등록 모델이 필요하다. 등록 모델을 찾을 수 없다면 저장된 기체 정의를 확인하고 그 PC에서 다시 등록한다.

**12. 자주 막히는 경우**

| 화면의 문제 | 확인할 항목 |
|---|---|
| CAD는 보이는데 해석이 실행되지 않음 | 기체 정의가 완성돼 등록됐는지, 현재 CAD와 선택한 등록 모델이 일치하는지 확인한다. |
| 부품 역할을 지정하라는 안내 | 미지정 부품을 찾아 역할 적용을 누른다. |
| 공력 면에 연결하라는 안내 | 주익·꼬리날개·조종면으로 지정한 부품이 공력 면에 포함됐는지 확인한다. |
| 단면이 여러 겹이거나 끊겼다는 안내 | 내부 구조물이나 떨어진 외피가 선택되지 않았는지 확인하고 절단 위치를 바꾼다. |
| 같은 부품의 공력 구간이 겹침 | span 범위와 대칭 복제 여부를 확인한다. |
| 질량·관성 또는 CG 입력 오류 | 빈 값, 단위, CAD 원점, 관성 기준점·축·교차항 부호를 확인한다. 모르는 값을 0으로 채우지 않는다. |
| 기체 정의가 등록값과 다름 | 수정한 기체 정의를 새 버전으로 등록한다. |
| 좌우 대칭 트림 오류 | 기체 로컬 좌표에서 윈치 출구와 CG의 Y를 맞춘다. 현재 두 해석 조건은 비대칭 트림을 지원하지 않는다. |
| 공력 범위 이탈 또는 트림 실패 | 축 방향·CG·질량·공력 면·추력을 먼저 점검한다. 필요한 운용 범위가 표 밖에 있으면 적절한 범위로 다시 계산한다. |
| 최대 12개 CPU를 골라도 적게 사용함 | 가용 메모리와 현재 계산 단계를 확인한다. AVL의 실제 동시 실행 수는 실행 기록에 남는다. |
| 줄이 기체를 관통해 보임 | 길이 미리보기와 실제 접촉 해석을 구분한다. 현재 질점 해석에는 CAD 접촉 제약이 없다. |

구현과 검증 기록은 [기체 정의 기술 안내](aircraft_definition.md)에서 확인할 수 있다.


등록 모델이 없으면 해석 입력과 실행 버튼이 비활성화됩니다. 기체 정의에서 등록을 마치세요. 이전에 선택한 모델이 사라졌더라도 배치는 유지됩니다. 기존 결과는 최근 해석에서 열 수 있습니다. 고급 등록의 빈 설정 템플릿에는 물리값을 넣어 두지 않았습니다. 값을 채우고 `template_unfilled: false`로 바꾼 뒤 등록하세요.


## AVL + flow5 복합 공력표

해석 화면의 **공력 해석기 → AVL + flow5 복합**을 선택한다. 공력표 상세에서 정적 계수·조종 미계수·회전율 미계수의 출처를 각각 고를 수 있다. 기본 조합은 정적 계수와 조종 미계수가 flow5, 회전율 미계수가 AVL이다.

1. 기체를 불러와 부품·질량·CG·공력 면을 정의하고 등록한다. 기존 등록 모델에서 “Xref·Yref·Zref가 CG와 다릅니다”가 나오면 기체 정의에서 새 버전으로 등록한다. 기존 등록 파일은 수정하지 않는다.
2. **실제 해석기로 새 계산**을 고른다. 승강타 범위는 ±10° 안으로 지정한다. 두 해석기는 같은 받음각·옆미끄럼각·승강타 격자와 CG 기준점을 사용한다.
3. 입력 확인 후 실행한다. 선택한 CPU 수를 두 해석기에 나눠 할당한다. 최대 12개이며, 가능한 경우 4개를 남긴다. AVL은 메모리 여유에 따라 작업 수를 더 줄일 수 있다.
4. 결과 카드와 보고서에서 블록별 출처, flow5 계산 속도, 다섯 가지 기울기의 차이를 확인한다. 상대 차이가 20%를 넘으면 점검 문구가 표시된다. 이는 해석기 간 차이이며 실물 정확도나 안전성의 합격 기준이 아니다.
5. 같은 등록 모델·속도·출처 조합이면 저장된 복합 표를 다시 쓸 수 있다. flow5가 들어간 표는 속도가 바뀌면 다시 계산한다.

세 블록의 출처가 모두 같으면 해당 단일 해석기를 선택한다. 회전율을 flow5에서 가져올 때만 기체 정의의 **flow5 종·횡 분리 근사 사용에 동의**가 필요하다. 회전율 출처가 AVL이면 이 확인 없이 복합 계산할 수 있다.

flow5 연결은 VLM2 양력면 범위다. 동체 공력과 상세 후류는 포함하지 않는다. 기존의 추가 항력 입력은 계속 적용한다. 두 해석기의 격자·형상 해시·기준 치수·CG 기준점이 다르면 조합을 거부한다. 서로 다른 저장 표를 보간하거나 외삽해서 맞추는 기능은 넣지 않았다.

공력표 생성이 끝나도 트림이 실패할 수 있다. 현재 트림은 좌우 대칭 직선비행만 지원하며, 실제 flow5 결과의 작은 횡방향 힘·모멘트가 허용 잔차를 넘는 경우에도 중단한다. 이때 고유값을 계산하거나 자동으로 다른 해석기로 바꾸지 않는다. 결과의 **공력 출처·비교**에서 원본을 확인하고 CG·형상 대칭·공력 범위를 점검한다. 조합을 바꾸려면 출처를 직접 선택하고 새 계산을 실행한다. [실제 확인한 제한과 실행 기록](FLOW5_CONNECTION.md#브라우저-연결-검증에서-확인한-트림-제한)을 참고한다.
