# 설계팀 자료 전달 양식

CATIA 파일을 받는 것과 해석 입력이 완성되는 것은 별도 단계다. 아래 정보를 함께 받으면 예시 기체를 팀 기체로 교체할 수 있다.

| 항목 | 필요한 내용 |
|---|---|
| 형상 | 기체·센서·문·가이드·포획부가 분리된 STEP, 표시용 STL |
| 좌표 | 원점, 각 축의 양의 방향, 길이 단위, 기체 CG와 각 부품 기준점 |
| 날개·꼬리날개 | 단면별 위치·시위·비틀림·에어포일 좌표, 조종면 힌지와 가동 범위 |
| 질량 | 기체 본체, 센서, 견인선, 배터리·윈치의 포함 여부를 구분한 질량표 |
| 관성 | CG 기준 3×3 관성 텐서, 곱관성의 부호 규약 |
| 장착점 | 기체 견인점과 센서 견인점, 줄이 통과하는 가이드의 위치 |
| 문·출구 | 문 회전축과 개방각 이력, 출구 크기, 내부 이동 경로, 여유 치수 |
| 견인선 | 전체 길이, 직경, 단위길이 질량, 인장 강성, 감쇠, 허용 장력 |
| 윈치 | 드럼 반경, 전개·회수 속도 이력, 토크·출력 한계, 센서 고정 해제 시점 |
| 포획부 | 접촉 재료·완충거리·강성·감쇠·마찰, 포획 가능한 위치·각도·속도 |
| 비행 | 속도·고도·밀도·바람, 조종면 한계와 예상 조종 입력 |

`intake.csv`에 값·단위·출처·자료 상태를 적는다. 가정값은 측정값으로 표시하지 않는다. 기체 mass에는 별도 모델로 계산하는 센서와 견인선을 다시 넣지 않는다. STEP/STL을 읽었다는 이유로 관성·항력·접촉 물성이 확보됐다고 보지 않는다.

인수 후에는 좌표와 질량 합계를 먼저 확인하고, AVL 기체 단독 공력·트림을 검토한 다음 결합 모델을 실행한다. 후방 개구부의 CFD·풍동·시험 결과가 있으면 센서 국소 유속과 노출 근사의 보정 자료로 별도 반영한다.
