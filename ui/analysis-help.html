질점 모델과 해석 조건

기체 CAD와 윈치 위치, 질점 질량, 줄 길이를 설정합니다. 센서 CAD·회전·관성·표면 연결점은 사용하지 않습니다. 질점의 중력과 줄 장력을 계산하고 기체 공력은 등록된 실제 AVL/flow5 공력표에서 가져옵니다.

좌표와 기체 등록

내부 길이는 m, 좌표는 전방 X · 우측 Y · 하방 Z입니다. 화면 위치는 mm입니다. 기체 CAD의 CG는 파일 원점 기준이며 aircraft.cg_m는 AVL 형상 기준 CG입니다. 새 기체는 질량·관성·CG와 공력 형상을 직접 등록하세요. 센서 CG는 질점 자체이므로 따로 입력하지 않습니다.

비행 시작 → 전개 → 전개 후 비행 → 회수

기본 해석은 입력한 고도·속도로 이미 비행 중인 수납 상태에서 시작합니다. 전개 전 비행 시간, 전개 평균 속도, 전개 후 비행 시간(기본 60초), 회수 평균 속도, 회수 후 남길 줄을 설정합니다. 전개·회수 구간에서도 직전 위치·속도를 이어 계산합니다. 이륙·포획·문 닫힘은 계산하지 않습니다.

화면에서는 질점을 윈치 가까이에 표시하며, 시작 줄 길이는 min(20 mm, 전개 목표 길이의 5%)입니다. 입력한 줄 길이는 전개 목표입니다. 결과 CSV와 3D 재생에서 구간명과 줄 길이를 확인할 수 있습니다.

단독 해석

전개 비행과 회수 단독 해석은 줄을 완전히 펼친 비행 평형에서 시작합니다.

전개 비행은 줄 길이를 유지하며 트림·동적 안정성·시간응답을 함께 계산합니다. 고유값은 제어·돌풍·조종 입력이 없는 평형을 기준으로 하고, 입력한 제어·돌풍·조종 이력은 시간응답에만 적용합니다.

회수는 전개 과정을 거치지 않고 바로 줄을 감습니다. 평균 속도와 회수 후 남길 줄 길이로 계산 시간을 정합니다. 줄 길이는 완만한 가감속 곡선을 20구간으로 나누어 적용하며 최대 속도는 평균의 약 1.5배입니다. 줄 분할 경계를 지날 때 적분을 나누어 계산합니다. 문은 불러온 각도를 유지하고 포획·문 닫힘은 계산하지 않습니다.

질점의 회전과 센서·기체·문·가이드 접촉은 계산하지 않습니다. 화면의 구는 위치 표시용입니다. 줄의 질량·공력·탄성·감쇠는 계산합니다. 회수 목표 길이에 도달했다는 표시는 실물 포획 성공을 뜻하지 않습니다.

공력 계산 범위

받음각·옆미끄럼각·승강타각의 최소·최대·계산점 수를 슬라이더로 조절합니다. 슬라이더를 움직이면 해당 각도의 계산점을 같은 간격으로 만듭니다. 세 목록의 모든 조합을 실제 AVL 또는 flow5로 계산하며 전체 조건 수를 화면에 표시합니다. 저장된 공력표를 사용할 때는 범위 슬라이더가 잠깁니다. 범위를 바꾸려면 새 계산을 선택하세요.

고도·속도 제어

해석 화면에서 승강타·추력으로 고도와 속도 유지를 켭니다. 위에서 입력한 고도·속도가 목표가 되고 비행 시작부터 전개·유지·회수까지 적용됩니다. 고도 오차·상승률로 목표 피치를 정하고 승강타로 피치·피치율을 조절합니다. 속도 오차는 추력으로 보정합니다. 고유값은 제어 없는 평형에서 계산합니다.

제어기 설정이 없던 프로젝트에는 시험용 기본 이득을 표시합니다. 세부 JSON의 altitude_kp_deg_m, climb_kd_deg_per_m_s, pitch_kp, pitch_rate_kd_s, airspeed_kp_N_per_m_s가 각각 고도·상승률·피치·피치율·속도 이득입니다. elevator_pitch_sign이 from_aero이면 실제 공력표의 CG 피칭 모멘트 기울기로 승강타 방향을 정합니다. 각도·추력 제한은 공력표·기체 한계를 넘을 수 없고 초기 트림값을 포함해야 합니다. 적분 보상이 없어 작은 정상 오차가 남을 수 있습니다. 기체별 조정과 시험 검증이 필요합니다.

결과 그래프에는 목표·실제 고도와 속도, 승강타·추력이 추가됩니다. 요약에는 최대 오차와 승강타·추력이 제한값에 머문 시간 비율이 저장됩니다. 롤·방향 제어, 센서 잡음, 통신 지연, 서보 응답 지연은 포함하지 않습니다.

돌풍과 조종 입력

아래 형식은 설치된 계산 코드의 입력 규약입니다. 바람은 NED 지면 좌표(북·동·하방), 속도 단위는 m/s입니다.

{"start_s": 3, "duration_s": 1, "velocity_ned_m_s": [0, 2, 0]}

3초부터 1초 동안 동쪽으로 최대 2 m/s인 사인 제곱 돌풍입니다. 돌풍이 없으면 null을 입력하세요.

{"elevator_delta_deg": [[0, 0], [1, 0], [1.1, 1], [2, 1]],
 "thrust_delta_N": [[0, 0], [1, 0]]}

승강타와 추력은 트림값에 더합니다. aileron_deg와 rudder_deg는 절대 조종각입니다. 조종 이력이 없으면 {}를 입력합니다. 제어기는 등록 설정의 flight.controller 항목을 사용하며 완전한 상태 측정과 즉시 작동하는 제한형 구동기를 가정합니다. UI의 제어 체크박스와 고도·속도 목표가 해당 입력을 덮어씁니다.

공력표와 검증 범위

다른 등록 모델의 공력표는 사용할 수 없습니다. flow5 결과는 계산 속도도 일치해야 합니다. 고유값은 고정 길이·비접촉 평형에서 계산합니다. 접촉하는 가이드와 회수 동작은 시간응답으로 확인하세요. 계산 완료는 수치 수렴이나 실물 검증 완료를 뜻하지 않습니다.
