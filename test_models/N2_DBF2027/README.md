# N2 — 새 기체로 UI·AVL 연결 확인

2026-09-26에 만든 독립 시험 기체다. 기존 H1 공력표를 재사용하지 않았다. `build_model.py`의 공통 날개·꼬리날개 치수로 CadQuery 솔리드와 AVL 입력을 생성했고, UI에서 새 모델로 등록한 뒤 AVL 3.52를 실제 실행했다.

| 항목 | 값 |
|---|---|
| 형상 | 고익, 앞 프로펠러, 일반 꼬리날개, 삼륜 착륙장치 |
| 날개폭 / 기준 면적 | 1.70 m / 0.4512 m² |
| 외곽 길이 / 높이 | 1.262 m / 0.583 m |
| 질량 | 기체 2.18 kg + 질점 0.10 kg + 줄 0.0042 kg |
| 줄 | 2.80 m, 직경 1 mm, 선밀도 1.5 g/m |
| 비행 조건 | 25 m/s, 100 m, 밀도 1.2133 kg/m³ |
| 윈치 출구 · CG 기준 FRD | [-0.4041972477, 0, 0.0781766055] m |
| 문 | 하부에 접힌 개방 형상, 270° 기준 |

질량은 실측값이 아닌 설계 가정이다. `mass_budget.csv`에 부품별 질량·위치·크기를 적었고, 관성은 부품별 상자 근사와 평행축 정리로 구했다. 고정 윈치는 기체 질량에 포함하고, 질점과 줄은 따로 계산한다. 동체·착륙장치·문 항력은 미측정 CD0=0.035로 보완했다. 후류·프로펠러 유동은 검증하지 않았다.

## DBF 조건 반영 범위

[AIAA 공식 페이지에 연결된 2026–27 규정](https://aiaa.org/wp-content/uploads/2026/09/DBF-2027-Rules-Draft.pdf)을 확인했다. 파일명은 Draft이며 원본 PDF도 이 폴더에 보존했다.

- §3.1: 날개폭 제한 6 ft=1.8288 m에 대해 N2는 1.70 m다.
- §3.1.2: 출구–센서 앞끝 전개 거리 기준은 날개폭의 1.5배, 즉 N2에서 2.55 m다. 줄 길이는 2.80 m이며, 32구간 평형의 출구–질점 직선 거리는 약 2.7514 m다. 질점은 센서 앞끝을 대신하는 계산 가정이다.
- 내부 수납을 고려해 빈 화물실과 후방 개구부를 만들었다. 210×100×110 mm 상자 공간을 설계에 잡았다. 실제 센서·수납함은 이번 질점 해석에 넣지 않았다.

센서 최소 길이·등화·전기 연결·회수 구속, 임무 수행·이륙·구조 시험 등의 적합성은 이 모델로 입증하지 않았다. **규정 치수를 반영한 해석용 시험 형상이며, 대회 적합 인증 모델은 아니다.**

## 다시 열기

가장 간단한 방법은 DBF Studio의 **프로젝트 열기**에서 `N2_ready.dbf.json`을 선택하는 것이다. 현재 설치에 등록된 N2 물성과 공력표 선택이 포함돼 있다.

형상만 시험하려면 `N2_aircraft_open.glb`를 **m / X 앞·Y 위·Z 오른쪽** 설정으로 가져온다. 파일 선택과 3D 화면 드롭을 지원한다. STEP 파일은 **mm / FRD**다. 새 기체를 가져오면 기존 윈치·질점을 비우므로 다시 배치한다. 최근 파일 버튼은 드래그하거나 눌러 다시 가져올 수 있다.

다른 설치에서는 GLB를 배치하고 윈치·질점을 추가한 뒤, **현재 CAD를 새 해석 모델로 등록**에서 다음을 입력한다.

1. 물성: `N2_case.yaml`
2. 공력: `aero/N2.avl`, `aero/n2_2412.dat`, `aero/n2_0010.dat`를 함께 선택
3. 기체 CAD CG: `[0,0,0]`
4. 문 이름: `["door_folded_270"]`, 기준 각도: `270`
5. 새 공력표 계산: AVL, 최대 12개 CPU

GLB와 STEP는 같은 최종 형상이지만 메시 구성이 다르다. GLB로 등록한 모델에 STEP 메시를 대체하면 형상 서명 확인에서 거부된다. STEP를 사용하려면 별도로 등록한다.

## 확인한 결과

실제 파일 선택 → 최근 파일 카드에서 캔버스로 마우스 드래그 → 윈치 드래그 → 질점 생성 → 새 모델 등록 → 해석 실행 → 3D 재생을 UI에서 수행했다. 탐색기에서 브라우저로 끄는 외부 파일 드래그 동작 자체는 자동화 도구 제한으로 검증하지 못했다.

AVL은 받음각 5 × 옆미끄럼 3 × 승강타 3 = 45조건을 12개 작업자로 새 계산했다. 실행 입력·출력과 형상 해시를 보존했다.

| 해석 | 결과 |
|---|---|
| 기체 단독 트림 | 받음각 −1.9369°, 승강타 3.3126°, 추력 5.4606 N |
| 질점 연결 트림 · 16구간 | 받음각 −1.9129°, 승강타 3.5022°, 추력 6.2712 N |
| 기체 단독 안정성 | 검사한 선형 모드에 불안정 모드 없음 |
| 질점 연결 안정성 | 양의 실수 고유값 존재. 32구간에서 +0.03408 s⁻¹ |
| 분할 민감도 | 주요 양의 고유값 변화: 8→16 약 4.67%, 16→32 약 1.27% |
| 피치 1° 교란, 2초 응답 | 최대 장력 1.2138 N, 초기 자세 대비 최대 피치 변화 0.2216° |
| 질량 수지 | 전 표본에서 2.2842 kg 유지 |

느린 불안정 모드는 선형 계산상 진폭이 약 20.3초에 두 배가 되는 값이다. 2초 재생으로 장시간 발산을 확인했다고 볼 수는 없다. 분할 비교는 주요 고유값에 한정되며, 전체 공력·과도응답 수렴 검증을 완료했다는 뜻은 아니다.
