# R3 고익기 시험 모델

기체 외형과 회수장치 배치를 함께 검토하기 위해 만든 가정 설계다. 실제 팀 기체나 제작 승인 형상이 아니다.

| 항목 | 입력값 |
|---|---:|
| 주익 폭 | 1.800 m |
| 주익 기준 면적 | 0.555 m² |
| 평균 공력 시위 | 약 0.30949 m |
| 주익 뿌리 / 끝 시위 | 0.335 / 0.275 m |
| 바깥 주익 상반각 | 4° |
| 주익 장착각, 뿌리 / 끝 | 2° / 1° |
| 동체와 꼬리붐 길이 | 1.560 m |
| 수평꼬리 폭 | 0.700 m |
| 프로펠러 표시 지름 | 0.370 m |
| 기체 가정 질량 | 2.300 kg |
| 센서 / 전체 줄 질량 | 0.040 / 0.00225 kg |
| 센서 길이 / 몸체 지름 / 핀 폭 | 120 / 28 / 46 mm |
| 후방 출구 폭 / 높이 | 56 / 70 mm |
| 포획 가이드 목의 폭 / 높이 | 50 / 50 mm |
| 문 최대 개방각 | 140° |

동체는 앞·뒤가 닫힌 곡면 외피다. 센서 출구 위로 꼬리붐을 연결하고, 기존 H1 아래쪽의 긴 절개를 없앴다. 주익·꼬리의 평면형, 비틀림과 상반각은 표시 형상과 AVL 입력에 함께 반영했다. 익형 좌표는 이 프로젝트에 복사되어 있던 H1 자료를 사용했다.

STEP은 정적 자세의 B-rep 조립체다. CATIA의 힌지 구속이나 모터가 들어 있는 운동 조립체는 아니다. 도어·센서·줄의 운동은 별도 계산 코드의 저장 결과를 재생한다. `cad`의 도어 이름에 남은 `100deg`는 기준 원본 자세이며, 위 `operating_cad`에는 문판·힌지 오프셋과 표시 각도를 적용했다.

## 좌표와 단위

STEP은 **mm, 기체 CG 원점, 전방–우측–하방(FRD)**이다. `meshes/*_FRD_m.stl`과 운동 입력은 같은 좌표의 **m** 단위다. 기수 기준 뒤쪽–우측–위쪽 좌표에서 기체 CG는 `(0.5049248043, 약 0, 0.0218857939) m`다. 이는 센서와 줄을 제외한 기체의 무게중심이다.

| 운동 모델의 위치 | CG 기준 FRD / m |
|---|---|
| 센서 수납 중심 | (−0.48507520, 0, 0.04188579) |
| 줄 출입점 | (−0.31507520, 0, 0.04188579) |
| 후방 출구 x | −0.63507520 |
| 도어 힌지 | (−0.63807520, 0, 0.07288579) |

개별 부품의 가정 질량을 CAD 부피에 배분해 무게중심과 관성을 구했다. 부품 재료나 실측 질량으로 검증한 값은 아니다. 센서·줄 질량은 기체 질량에 중복해서 넣지 않는다. 문 관성은 닫힌 상태로 고정한 근사다.

## 해석과 재생성

프로젝트 루트의 `examples/h1_normal_r3.yaml`과 `test_models/H1_reference/runs/normal_r3_01/aerodynamics/aero_database.npz`가 짝이다. 이전 H1 공력표로 이 형상을 계산하면 안 된다. 실제 AVL 출력과 [분포 양력](../../runs/normal_r3_01/aerodynamics/aero_report.html), [기체 단독 교란 응답](../../runs/normal_r3_01/airframe_response/response.html)을 함께 제공한다.

형상 생성기는 `test_models/H1_reference/build_normal_aircraft.py`다. 기존 출력이 있으면 덮어쓰지 않는다. 형상을 바꾸면 CAD, 메시, 질량 정보, AVL 입력을 함께 생성하고 공력표도 새로 계산해야 한다.

도어 회전의 181개 자세와 정렬된 센서·직선 줄의 41개 위치를 확인했다. 이 정적 검사는 전개·회수 성공이나 연속 시간 전체의 무간섭 증명이 아니다. 접촉 반력, 포획 성공과 수치 수렴은 운동 결과에서 따로 확인한다. 힌지·기어·완충부의 상세 제조 구조, 열린 출구 유동과 프로펠러 후류, 부품 강도는 아직 검증하지 않았다.
