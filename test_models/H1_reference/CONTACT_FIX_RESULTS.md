# H1 관통 수정 결과

센서 전체 형상과 와이어 각 구간에 접촉 반력을 추가하고, 관통 위험이 생기면 계산을 중단하도록 수정했다. 처음부터 다시 계산한 두 궤적의 **저장 상태 각 638개에서 CAD 겹침과 검사 오류가 모두 0건**이었다.

**정상 회수·포획은 아직 완료하지 못했다.** 두 계산 모두 약 6.17초에 와이어–출구 상단의 거리 한계로 중단됐다. 요청한 7초까지 계산한 결과가 아니며, 남은 구간이나 포획·문 닫힘을 만들어 넣지 않았다.

## 재계산과 시간 간격 비교

두 경우 모두 같은 물성과 실제 H1 AVL 공력표를 사용해 0초부터 계산했다. 비교 계산은 접촉 근처·원거리의 표면 이동 상한을 각각 절반으로 줄이고 최대 적분 간격도 줄였다. 서로 다른 물리모델의 앞·뒤 구간을 이어 붙이지 않았다. 사용한 계산 코드의 해시는 [실행 시 소스 기록](runs/contact_corrected_06/source_versions.json)에 보존했으며, 해당 검증 당시 파일과 일치했다. 이후 도어 힌지·개방각 수정 결과는 별도 실행 기록으로 관리한다.

| 지표 | 기준 | 더 작은 시간 간격 | 변화율 |
|---|---:|---:|---:|
| 종료 시각, 초 | 6.171852 | 6.171119 | 차이 0.000733초 |
| 최대 장력, N | 44.37194 | 44.17434 | 0.445% |
| 최대 기체 피치 변화, ° | 3.25579 | 3.25599 | 0.0059% |
| 최대 접촉 법선력 합, N | 576.25097 | 575.02170 | 0.213% |
| 접촉 법선력 합의 시간 적분, N·s | 8.13775 | 8.38398 | 2.937% |
| 포획 | 실패 | 실패 | 동일 |
| CAD 검사 시각 / 겹침 / 검사 오류 | 638 / 0 / 0 | 638 / 0 / 0 | 저장 상태 전체 검사 |

변화율은 두 값 중 큰 절댓값을 분모로 계산했다. 위 네 하중·자세 지표는 5% 비교 목표 이내였다. **중단 시점까지의 시간 간격 비교**이며, 7초 전 과정이나 줄 10→20→40구간의 수렴을 확인한 것은 아니다. 따라서 `numerically_converged=false`를 유지한다. 같은 시각으로 보간한 장력 이력의 최대 차이는 약 1.95N, 센서 앞뒤 위치의 최대 차이는 약 5.91mm였다.

최대값과 충격량은 저장 시간 표본에서 계산했다. 더 좁은 충격 피크는 별도 출력 간격 검사가 필요하다. 접촉 강성·감쇠는 실측값이 아닌 수치 설정이므로 위 수치를 제작용 충격 하중으로 확정하지 않는다. 계산 시간은 기준 약 31.2분, 비교 약 34.2분이었다. 재생 화면은 이 오프라인 계산 결과를 보여준다.

## 중단 원인과 판정

양쪽 모두 첫 와이어 구간(`cable_span_0`)이 출구 프레임 상단(`rear_exit_frame_ceiling`)에 접근해, 실제 메시 거리 0.02mm에서 `contact_clearance_limit`으로 중단됐다. 이는 가정한 접촉 모델의 계산 경계이며 실물 장치의 고장 시각을 검증한 값은 아니다.

기준 계산에서 최대 장력은 입력 한계 8N을 넘었다. 요구 토크 약 0.666N·m와 출력 약 18.68W도 입력 한계 0.15N·m, 5W를 초과했다. 현재 윈치는 지정 속도를 유지하며 필요한 구동력을 계산한다. 실제 모터의 토크 한계에 따른 감속·정지를 구현한 모델이 아니다.

마지막 센서 위치는 포획 목표에서 약 221.3mm 떨어져 있고, 상대속도는 약 8.62m/s, 상대각은 약 15.09°다. 입력 포획 기준인 6mm, 0.15m/s, 8°를 충족하지 못했다. 현재 형상과 명령으로 정상 회수가 입증됐다고 판정하지 않는다.

## 수정 범위와 남은 일

[접촉 모델 설명](../../docs/CONTACT_MODEL.md)에 전체 형상 검사, 접촉 반력과 기체 반력, 와이어 접촉점의 연속성, 단계별 표면 이동 제한을 정리했다. 자동 검사 **39개가 통과**했으며 기록은 `../../outputs/validation/contact_tests.xml`에 있다. 재생·반복 재생·내부 보기와 공력 출처 표시도 브라우저에서 확인했다.

OpenCASCADE 검사는 총 1,276개 저장 상태의 실제 STEP 형상 교차 검사다. 연속 시간 전체의 CAD 무간섭 증명은 아니다. 입력·상태·CAD·검사 스크립트 해시를 각 검사 기록에 남겼다. 윈치 내부의 이상적인 줄 출입과 시각화용 견인점은 제외했으며, 센서–윈치 접촉은 포함했다. 줄 자체 접촉과 줄–센서 접촉은 아직 포함하지 않는다.

기체 양력면 공력은 실제 AVL 3.52의 105조건 결과다. flow5는 아직 연결하지 않았고, 센서·줄 공력, 추가 항력과 후류는 가정 모델이다. 공력 보간 정밀도와 센서·후류 입력의 검증, 줄 출입 에너지 수지와 공간 분할 수렴, 윈치 구동 한계 및 출구 안내·회수 조건의 개선이 남아 있다. 이전 관통 궤적과 실패·중단 기록은 재현을 위해 보존했다.
