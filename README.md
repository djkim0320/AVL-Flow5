# DBF Studio · AVL/flow5 안정성 해석

기체 CAD에 윈치와 센서 역할의 질점을 배치하고, 비행 시작부터 줄 전개·유지 비행·회수까지 연속 계산하는 범용 연구용 도구입니다. 기체마다 부품·질량·무게중심(CG)·관성·공력 면을 등록해 사용합니다.

[사용설명서](docs/사용설명서.md) · [UI 사용법](ui/README.md) · [설치·배포 범위](docs/REPOSITORY.md)

## 주요 기능

| 기능 | 내용 |
|---|---|
| 기체 불러오기 | STEP·STL·GLB를 불러와 단위와 축 방향 확인 |
| 기체 정의 | 부품 역할 지정, CG 배치, 질량·관성·공력 면·조종면 입력 |
| 윈치·질점 배치 | 윈치 위치를 드래그로 설정하고 질점 질량·줄 길이 입력 |
| 공력 계산 | 실제 MIT AVL 3.52, flow5 7.57 또는 두 해석기의 복합 공력표 사용 |
| 전개 비행 | 완전 전개 상태의 트림, 고정 길이 평형의 고유모드, 교란 응답 계산 |
| 연속 해석 · 기본 | 줄이 감긴 비행 상태에서 전개·유지 비행·회수를 하나의 궤적으로 계산 |
| 회수 | 완전 전개 평형에서 줄을 감으며 기체 자세·장력·윈치 요구량 계산 |
| 결과 확인 | 계산 조건·공력 출처, 시계열 CSV, 보고서·그래프·3D 재생 저장 |

## GitHub에서 받아 실행하기

Windows와 Python 3.11 이상, Node.js/npm이 필요합니다.

```powershell
git clone https://github.com/djkim0320/AVL-Flow5.git
cd AVL-Flow5
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[contact,dev]"
npm.cmd --prefix ui ci
.venv\Scripts\python.exe scripts/fetch_avl.py
.venv\Scripts\python.exe scripts/fetch_flow5.py
.\Start_DBF_UI.bat
```

설치 후에는 `Start_DBF_UI.bat`를 더블클릭해 실행합니다. 브라우저가 열리지 않으면 서버 실행 후 [DBF Studio](http://127.0.0.1:8767/)에 접속하세요.

AVL과 flow5는 설치 스크립트로 내려받으며 실행파일 해시를 검사합니다. 실행파일이 없거나 계산에 실패하면 오류로 중단합니다. 배포 출처와 라이선스 정보는 [외부 구성요소 안내](docs/THIRD_PARTY.md)에 있습니다.

## 사용 순서

1. 문이 열린 기체 CAD를 불러오고 단위·축 방향을 확인합니다.
2. 윈치를 추가해 위치를 정하고 질점 질량·줄 길이를 입력합니다.
3. **기체 정의**에서 부품 역할, 질량·CG·관성, 공력 면과 조종면을 입력해 모델을 등록합니다.
4. **해석**의 기본 조건인 **비행 시작 → 전개 → 전개 후 비행 → 회수**에서 비행 조건·줄 물성·계산 범위와 시간을 설정합니다. 전개 후 비행은 기본 60초입니다.
5. **입력 확인 → 해석 실행** 후 결과와 적용 범위를 확인합니다.

CAD 형상만으로 질량·관성·공력 입력이 모두 정해지지는 않습니다. 등록 정보가 부족하거나 현재 CAD와 맞지 않으면 해석을 시작할 수 없습니다. 내부 단위는 SI, 기체축은 FRD(X 전방·Y 우측·Z 하방)입니다.

## AVL + flow5 복합 공력표

해석 화면에서 **AVL + flow5 복합**을 선택하면 정적 계수·조종 미계수·회전율 미계수의 출처를 각각 지정할 수 있습니다. 기본 조합은 정적·조종 계수에 flow5, 회전율 미계수에 AVL을 사용합니다.

두 해석기는 같은 형상·격자·CG 기준점에서 계산합니다. 형상 해시, 기준 치수와 기준점이 맞지 않으면 조합을 거부하며, flow5가 포함된 저장 표는 계산 속도가 같아야 재사용할 수 있습니다. 결과에는 선택한 출처와 원본 기록을 남기고, 두 해석기의 기울기 차이가 20%를 넘으면 점검 문구를 표시합니다.

선택한 계산 자원을 두 해석기에 나눠 할당합니다. 최대 12개 CPU를 사용하고 가능한 경우 4개를 남깁니다. AVL은 가용 메모리에 따라 동시 실행 수를 더 줄일 수 있습니다.

공력표 생성과 트림 성공은 별도입니다. 기본 flow5 정적 조합에서 작은 횡방향 잔차가 대칭 트림의 허용치를 넘긴 사례가 있습니다. 허용오차를 늘리거나 출처를 자동으로 바꾸지 않습니다. 자세한 조건과 제한은 [복합 공력표 안내](docs/FLOW5_CONNECTION.md#복합-공력표--구현-기준)를 참고하세요.

## 해석 범위와 한계

센서는 형상 없이 질량과 병진 운동만 있는 질점입니다. 중력과 줄 장력을 계산하며 센서 공력·회전·CAD 접촉은 포함하지 않습니다. 줄에는 질량·공력·탄성·감쇠를 적용합니다.

기본 연속 해석은 입력한 고도·속도로 이미 비행 중인 수납 상태에서 시작합니다. 시작 줄 길이는 min(20 mm, 전개 길이의 5%)이며, 전개 전 비행 시간·전개 평균 속도·전개 후 비행 시간·회수 평균 속도·회수 후 남길 줄 길이를 설정합니다. 구간 사이 기체·질점의 위치와 속도를 이어 계산합니다. 전개·회수는 완만한 가감속 곡선의 20구간 근사로, 최대 속도는 평균의 약 1.5배입니다. 문은 불러온 각도를 유지하며 이륙·포획·문 닫힘은 계산하지 않습니다.

**전개 비행 · 안정성 단독 해석**과 **회수만 단독 해석**도 선택할 수 있습니다. 두 단독 해석은 완전 전개 평형에서 시작합니다. 트림은 무풍·대칭·수평 직선비행을 지원합니다. 고유값은 고정 길이 평형 주위의 결과이며, 길이가 변하는 연속 해석은 시간응답으로 평가합니다.

flow5 연결은 동체를 제외한 VLM2 양력면 해석입니다. 상세 후류와 실물 물성, 수치 수렴은 별도 검증이 필요합니다. **계산 완료는 실제 기체의 안전성이나 회수 성공을 입증하지 않습니다.**

## 검사

설치 후 저장소에 포함된 생성 기체를 사용하는 검사를 실행할 수 있습니다.

```powershell
.venv\Scripts\python.exe -m unittest discover -s ui/tests
npm.cmd --prefix ui run check
npm.cmd --prefix ui test
.venv\Scripts\python.exe -m pytest -q tests/test_hybrid_compose.py tests/test_ui_generated_pipeline.py
```

마지막 명령에는 실제 AVL·flow5 실행 검사가 포함됩니다. 전체 `tests/` 중 별도 보관된 계산 자료가 필요한 회귀 검사는 소스 배포본만으로 실행할 수 없습니다. [검증 범위와 실행 기록](docs/REPOSITORY.md#검사-범위)을 확인하세요.
